# mcp_practice

A hands-on workshop: write a minimal local "Notes" MCP server in Python, connect it to Claude Code, and explore tools, resources, and prompts.

- Python, [`mcp`](https://py.sdk.modelcontextprotocol.io) SDK 2.3.0, [`uv`](https://docs.astral.sh/uv/)
- Runs locally over stdio, with Claude Code as the client: no API keys, no hosting

The full course with step-by-step tasks is in [COURSE.md](COURSE.md).
